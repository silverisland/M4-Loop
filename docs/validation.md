## 0.1.0 原始验证记录

日期：2026-10-20。测试使用人工数据，未进行真实电站训练或业务分数比较。

### 环境与结果

- Python 3.12.14、PyTorch 2.5.1、NumPy 2.3.5、Pandas 2.2.3、
  PyArrow 26.0.0、PyYAML 6.0.3、pytest 9.1.1。
- `python -m pytest -q`：**32 passed**。
- `python -m ruff check m4_loop examples tests`：通过。
- Python 编译检查：通过。
- 子进程测试在沙箱外运行：macOS 沙箱会阻止本地 OpenMP 共享内存初始化。
  这两项最初因环境限制中断，放行后通过，未跳过测试。

### 默认窗口

用默认 672 点历史、192 点未来输入，batch=2：

- 预测形状 `[2,192]`，embedding 形状 `[2,256]`。
- 有监督前向、反向通过；所有可训练参数均收到有限梯度。
- 保存并严格重载 checkpoint 后，eval 预测逐元素完全一致。

实测参数量：

| 配置 | 总参数量 | 编码器参数量 |
| --- | ---: | ---: |
| 默认：两层、两次循环 | 3,477,376 | 1,580,032 |
| 对照：四层、一次执行 | 5,056,896 | 3,159,552 |
| 对照：一层、四次循环 | 2,687,616 | 790,272 |

这些数量均来自本项目实例化模型，不是原 M4 checkpoint 的实测值。

### 独立性与训练链路

- 将 `m4_loop` 包复制到临时目录，以隔离 Python 子进程运行，显式阻止
  `m4`、`m1`、`forecast_backbones`、`NextGenPVForecast`、`pipelines`、
  `interfaces` 导入。前向、反向、Parquet 训练、checkpoint 保存与预测通过。
- 独立构建 wheel，并使用 `--no-index --no-deps --target` 安装到另一临时目录；
  已验证随包提供的默认 YAML 可读取。
- 在隔离解释器中使用安装后的包执行文档中的人工数据流程：24 行训练、8 行验证、
  两次优化，保存最佳权重后预测 8 行测试数据，输出长度均正确。
- 验证最佳模型保存：故意让第二轮指标退化，确认触发早停且 checkpoint 保存第一轮权重。
- 验证无标签推理、缺失标签过滤、容量广播、旧格式和不完整权重拒绝加载。
- 工作前后原 M4 目录的 9 个源码/配置文件 SHA-256 一致。
